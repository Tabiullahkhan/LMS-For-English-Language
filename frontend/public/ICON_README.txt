This project needs two real icon image files placed in this /public folder for the PWA
install prompt to look correct on phones:

  icon-192.png  (192x192 pixels)
  icon-512.png  (512x512 pixels)

Use the instructor's logo, or a simple "TK" monogram if no logo exists yet.
Free tool to generate both sizes from one image: https://realfavicongenerator.net

Until these exist, the site will still install as a PWA, but the home-screen icon
will look like a generic placeholder instead of the brand.
